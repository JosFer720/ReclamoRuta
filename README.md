# SiloAlerta

Proyecto final de CC3092 Deep Learning y Sistemas Inteligentes, UVG.

Aplicación propuesta para analizar grabaciones de sensores en muestras de productos almacenados y alertar sobre posible actividad de insectos.

## Estado

Preparación inicial: revisión documental de viabilidad y plan de trabajo. No hay modelo entrenado, dataset descargado, aplicación implementada ni resultados económicos medidos.
